# /plan - 기능 구현 계획 생성

Planner 에이전트에게 위임하여 구현 계획을 생성합니다.

## 사용법
```
/plan <기능 설명>
```

## 예시
```
/plan WebSocket으로 실시간 알림 추가
/plan 이력서 AI 분석 기능 구현
/plan 구글 OAuth2 로그인 추가
```

## 실행 과정
1. 현재 코드베이스 구조 분석
2. Planner 에이전트에 컨텍스트 전달
3. 단계별 구현 계획 생성
4. 체크리스트 형태로 출력

## 출력물
- 파일 구조 (생성/수정할 파일 목록)
- 작업 단계 (복잡도, 예상 시간 포함)
- 위험 요소 및 해결책
- 테스트 전략
