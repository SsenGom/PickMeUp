9. 실행 방법

# 1. Docker로 DB 실행
cd docker
docker compose -f docker-compose.dev.yml up -d

# 2. 백엔드 실행
cd backend
.\gradlew bootRun

# 3. 프론트엔드 실행
cd frontend
npm install
npm run dev
Frontend
http://localhost:3000
Backend
http://localhost:8080
Swagger
http://localhost:8080/swagger-ui
